# Sistema de Empréstimo de Itens

Projeto desenvolvido para a disciplina de **Verificação e Validação de Software**, com o objetivo de aplicar na prática as abordagens **TDD (Test Driven Development)** e **BDD (Behavior Driven Development)**.

## Sobre o projeto

O sistema tem como objetivo permitir o gerenciamento de empréstimos de itens, envolvendo funcionalidades como cadastro, consulta, empréstimo, devolução e controle das informações relacionadas aos usuários e aos itens.

O projeto foi dividido entre os integrantes da equipe, sendo cada integrante responsável pelo desenvolvimento e pelos testes de funcionalidades específicas.

## Metodologias utilizadas

### TDD
O desenvolvimento foi realizado seguindo o ciclo:

1. Criação do teste;
2. Execução do teste com falha (**RED**);
3. Implementação do código necessário;
4. Execução do teste com sucesso (**GREEN**);
5. Revisão e refatoração do código.

### BDD
Os comportamentos esperados das funcionalidades foram descritos por meio de cenários em **Gherkin**, utilizando a estrutura:

- **Dado** – contexto inicial;
- **Quando** – ação realizada;
- **Então** – resultado esperado.

## Tecnologias utilizadas

- Python
- unittest
- Gherkin / BDD
- Visual Studio Code

## Funcionalidades

Entre as funcionalidades desenvolvidas no projeto estão:

- Cadastro e consulta de usuários;
- Cadastro e consulta de itens;
- Registro de empréstimos;
- Devolução de itens;
- Renovação e consulta de histórico.

## Testes

Os testes automatizados foram desenvolvidos seguindo os conceitos de TDD, permitindo validar as regras implementadas e verificar se as funcionalidades apresentam os resultados esperados.

Os cenários BDD também foram utilizados para documentar os comportamentos e regras de negócio do sistema.
